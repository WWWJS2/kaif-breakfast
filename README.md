# كايف · دعوات تجربة الفطور

موقع دعوة (`index.html`) ولوحة تحكم محمية (`admin.html`)، بقاعدة بيانات Supabase تمنع تجاوز السعة حتى مع الطلبات المتزامنة.

## التشغيل الفعلي (حوالي 10 دقائق)

1. أنشئ مشروعًا مجانيًا على supabase.com.
2. من **SQL Editor** الصق محتوى `supabase/schema.sql` كاملًا واضغط Run.
   ينشئ الجداول، والدوال، والأيام (الأربعاء 11/11، الخميس 12/11، الجمعة 13/11)، والأوقات 6–7، 7–8، 8–9، والسعة 10.
3. من **Authentication → Users → Add user** أنشئ حساب الإدارة (بريد وكلمة مرور).
4. في SQL Editor نفّذ (بعد وضع بريدك):
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'YOUR-EMAIL' on conflict do nothing;
   ```
5. من **Project Settings → API** انسخ `Project URL` و `anon public key` إلى `assets/js/config.js`.
   مفتاح anon مصمم ليكون علنيًا؛ كل القواعد مطبقة داخل قاعدة البيانات، ولا يوجد أي مفتاح إدارة في الواجهة.
6. ارفع الملفات (عدا `node_modules` و`dev` و`tests` و`preview`) إلى GitHub Pages.
   رابط الدعوة: `https://…/` — لوحة التحكم: `https://…/admin.html`.

## كيف تُحمى السعة

- الزائر لا يستطيع قراءة أو كتابة أي جدول؛ يستدعي فقط `get_availability` و`create_booking`.
- `create_booking` تقفل صف اليوم (`FOR UPDATE`) فتُعالَج الطلبات لنفس اليوم واحدًا تلو الآخر، فيستحيل تجاوز 10.
- كل إرسال يحمل رمزًا فريدًا، فالضغط المزدوج أو إعادة المحاولة بعد انقطاع لا ينشئ حجزًا ثانيًا.
- صفحة الدعوة تحدّث التوفر كل 10 ثوانٍ وعند العودة للصفحة، فيُغلق اليوم المكتمل عند الجميع؛ وحتى لو تأخر التحديث يرفض الخادم الحجز.
- الإلغاء من اللوحة يعيد المقاعد، وإعادة تفعيل حجز ملغى تخضع للسعة نفسها.

## النصوص

- `assets/js/strings.js` قسم `ORIGINAL`: نصوص النموذج الأصلي حرفيًا.
- قسم `FUNCTIONAL`: رسائل وظيفية جديدة لم تكن في الأصل (مكتمل، الحجز مغلق، …) — استبدلها بالنص الأصلي إن وُجد.
  `CONFIRM_TITLE` فارغ عمدًا: ضع فيه نص التأكيد الأصلي ليظهر في بطاقة الدعوة.

## التطوير المحلي

```bash
npm install
node --test tests/db.test.mjs      # 7 اختبارات على قاعدة Postgres محلية (PGlite) بنفس schema.sql
node dev/server.mjs 5173           # خادم محلي يحاكي Supabase — بيانات الدخول في dev/dev-users.json
python3 tests/e2e.py OUTDIR        # 27 فحصًا شاملًا مع لقطات شاشة
node dev/build-preview.mjs         # نسخة معاينة بقاعدة بيانات داخل المتصفح (للمراجعة فقط)
```
